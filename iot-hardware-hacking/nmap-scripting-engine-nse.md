# Nmap Scripting Engine (NSE)



| **NSE Script Name**            | **Category / Target**                             | **Description**                                                                                                                                            |
| ------------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `broadcast-upnp-info`          | Reconnaissance (Discovery)                        | <p>Sends UPnP SSDP multicast request</p><ul><li>device name, model numbers</li></ul>                                                                       |
| `dns-service-discovery`        | Reconnaissance (Discovery)                        | <p>Queries mDNS (Bonjour/ZeroConf) on UDP 5353 </p><ul><li>resolve local home devices, printers</li></ul>                                                  |
| `upnp-info`                    | Reconnaissance (Discovery)                        | <p>Queries an exposed UPnP service directly</p><ul><li>internal XML schema URLs and capability mappings </li></ul>                                         |
| `hnap-info`                    | Reconnaissance (Discovery)                        | <p>Queries Home Network Administration Protocol (HNAP) endpoints on routers and gateways</p><ul><li>system hardware versions</li><li>vendor info</li></ul> |
| `broadcast-wsdd-discover`      | Reconnaissance (Discovery)                        | <p>Discovers devices implementing Web Services Dynamic Discovery (WS-Discovery)</p><ul><li>common in smart cameras, ONVIF nodes, and printers</li></ul>    |
| `snmp-sysdescr`                | Reconnaissance (Discovery)                        | Extracts system descriptions, uptime, and underlying OS build info via SNMP v1/v2c                                                                         |
| `snmp-interfaces`              | Reconnaissance (Discovery)                        | Enumerates network interfaces, MAC addresses, and local IP bindings on routers and managed gateways via SNMP                                               |
| `mqtt-subscribe`               | Service Auditing (MQTT / TCP 1883/8883)           | Connects to an MQTT broker, subscribes to wildcard topics (`#`), and collects published telemetry payloads, commands, and status messages                  |
| `coap-resources`               | Service Auditing (CoAP / UDP 5683)                | Queries Constrained Application Protocol endpoints to discover exposed resources and sensor URIs using CoAP discovery requests                             |
| `rtsp-url-brute`               | Service Auditing (RTSP / TCP 554/8554)            | Brute-forces valid media stream paths (e.g., `/live`, `/h264`, `/cam/realmonitor`) on IP cameras and NVR/DVR systems                                       |
| `rtsp-methods`                 | Service Auditing (RTSP / TCP 554/8554)            | Determines supported RTSP request methods (DESCRIBE, SETUP, PLAY) and server authentication policies                                                       |
| `tftp-enum`                    | Service Auditing (TFTP / UDP 69)                  | Tests for unauthenticated TFTP servers (often used by U-Boot bootloaders and legacy IP phones) and attempts common configuration file retrievals           |
| `modbus-discover`              | Service Auditing (Modbus TCP / TCP 502)           | Enumerates Modbus slave unit IDs and device information on industrial IoT (IIoT) gateways and PLCs                                                         |
| `bacnet-info`                  | Service Auditing (BACnet / UDP 47808)             | Discovers building automation nodes (HVAC, smart lighting, access control controllers) and retrieves vendor IDs and software revisions                     |
| `s7-info`                      | Service Auditing (Siemens S7 / TCP 102)           | Interrogates Siemens S7 PLC controllers to extract system hardware models, firmware versions, and module details                                           |
| `fox-info`                     | Service Auditing (Tridium Niagara Fox / TCP 1911) | Discovers Tridium Niagara building management framework servers and collects system metadata and app credentials                                           |
| `http-dlink-backdoor`          | Model/Vendor-Specific (D-Link Routers)            | Tests for a well-known User-Agent authentication bypass backdoor in legacy D-Link router firmware                                                          |
| `http-tplink-dir-traversal`    | Model/Vendor-Specific (TP-Link Devices)           | Checks for directory traversal vulnerabilities in embedded web servers on specific TP-Link routers and Wi-Fi extenders                                     |
| `http-huawei-hg530-backdoor`   | Model/Vendor-Specific (Huawei Gateways)           | Scans for an administrative interface backdoor on Huawei HG530 and related ADSL/fiber routers                                                              |
| `http-asuswrt-tr069-rce`       | Model/Vendor-Specific (ASUS Routers)              | Tests for remote code execution flaws within the TR-069 client daemon running on ASUSWRT firmware devices                                                  |
| `http-axis-cgi-dir-traversal`  | Model/Vendor-Specific (Axis IP Cameras)           | Tests Axis network cameras for path traversal flaws in legacy CGI scripts (`/incl/sysinfo.cgi`)                                                            |
| `http-hikvision-info`          | Model/Vendor-Specific (Hikvision Cameras)         | Extracts camera details, serial numbers, and configuration settings from vulnerable Hikvision IP camera web interfaces                                     |
| `http-avtech-dir-traversal`    | Model/Vendor-Specific (AVTech DVRs/Cameras)       | Checks for directory traversal and unauthenticated file disclosure vulnerabilities on AVTech security equipment                                            |
| `http-netgear-300-auth-bypass` | Model/Vendor-Specific (Netgear Routers)           | Tests for administrative authentication bypass flaws present in specific Netgear WNR series firmware builds                                                |
| `http-vuln-cve2017-5638`       | Model/Vendor-Specific (Embedded Apache Struts)    | Checks for remote command execution on higher-end IoT gateways and enterprise management consoles using vulnerable Struts components                       |
